# jeonse-data

전세보증금 앱이 쓰는 공개 데이터. **국토교통부 실거래가**를 집계해 매일 갱신한다.

## 소스

공공데이터포털 국토교통부 실거래가 6종 (**이용허락범위 제한 없음**)

| 폴더 | 내용 |
|---|---|
| `rent_apt` / `rent_rh` / `rent_offi` / `rent_sh` | 아파트·연립다세대·오피스텔·단독다가구 **전세**(월세 0)만 |
| `trade_apt` / `trade_rh` | 아파트·연립다세대 매매 |

## 파일

`data/{종류}/{시군구코드}.json` — 앱은 자기 시군구 파일 하나(약 20~30KB)만 받는다.

```json
{"updatedAt":"...","sgg":"11110","name":"서울특별시 종로구","count":344,
 "rows":[{"d":"구기동","a":"60~85","m":"202512","n":3,"med":40000,"lo":32500,"hi":67000}]}
```
`d` 법정동 · `a` 전용면적대(㎡) · `m` 계약월 · `n` 건수 · `med` 중앙값(만원) · `lo`/`hi` 최저·최고

## 설계 메모

- **원본을 그대로 두지 않는다.** 12개월 전량은 280만건·242MB라 매일 커밋하면
  git 이력이 감당이 안 된다. 법정동×면적대×월 중앙값으로 접어 1/50로 줄였다.
- **전세만 집계한다.** 전월세 자료엔 월세가 섞여 있는데 같이 넣으면 중앙값이
  끌려 내려가 "내 보증금이 시세보다 높다"는 잘못된 경고가 나온다.
- **최근 3개월은 매일 다시 받는다.** 실거래 신고 기한이 계약일+30일이라
  최근 달은 계속 차오른다.
- 🔴 **이 저장소는 public 이어야 한다.** public = Actions 무제한 무료.
  private 로 바꾸면 그 순간부터 분당 과금된다.

## 면책

국토교통부가 공개한 신고 자료를 집계한 것이다. **실거래가는 감정가가 아니며**
같은 단지도 층·향·상태에 따라 다르다. 거래가 없는 달은 값이 없다.
